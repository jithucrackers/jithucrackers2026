🎇 Jithu Crackers - Online Price List & Order System
Quality, Quantity & Trust.
A lightweight, mobile-first, "serverless" e-commerce solution for Sivakasi crackers.

🚀 Overview: 
Jithu Crackers is a fast, sleek, and responsive web application designed for browsing cracker price lists and placing orders via WhatsApp and Email. It operates entirely without a database, utilizing a JSON-based data structure and modern browser capabilities to handle orders, validation, and unique ID generation.

✨ Features: 
📱 Mobile-First Design: Optimized for high-speed browsing on smartphones.
💰 Dynamic Pricing: Automatically displays 75% discount off MRP (calculated as MRP + 10% then discounted).
🔢 Live Subtotals: Real-time calculation of item costs and grand totals.
📋 Order ID System: Generates unique, time-based IDs (YYYYMMDD-HHMMSS) to track orders across different devices.
💬 Sleek WhatsApp Integration: Sends formatted, bolded order summaries directly to the seller.
✉️ Email Support: Templates orders for professional email communication.
✅ Form Validation: Real-time validation for 10-digit phone numbers, emails, and address fields.
🛠 No Database Required: All product data is fetched from a local products.json file.
💾 JSON Export: Allows customers to download their order as a JSON file for record-keeping.

🛠 Tech Stack: 
HTML5: Semantic structure.
CSS3: Custom Flexbox and Grid layouts with mobile-safe UI components.
JavaScript (Vanilla): Data fetching, state management, and rounding logic.
JSON: Product catalog storage.
